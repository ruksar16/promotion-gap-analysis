# Career Progression and Promotion Gap Analysis for Retention Optimization at Palo Alto Networks

This project analyzes employee data to uncover **career progression patterns** and identify **employee retention risks** using data science and machine learning techniques.

## Project Overview
The objective of this project is to:
- Analyze employee dataset
- Identify career growth trends
- Detect employees at risk of leaving
- Provide HR insights using clustering techniques

## Files

- Nassau_Candy_Distributor.csv
- app.py
- Product_Profitability_Analysis_Nassau_Candy.ipynb
- requirements.txt
- README.md

## Technologies Used

- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn (KMeans, PCA, Clustering)
- SciPy
- Plotly
- Streamlit

## Key Features

- Data Cleaning & Preprocessing  
- Feature Scaling (StandardScaler)  
- KMeans Clustering  
- Hierarchical Clustering  
- PCA (Dimensionality Reduction)  
- Data Visualization (Seaborn, Plotly)  
- Streamlit Interactive Dashboard  

## Outputs

- career_progression_analysis_results.csv  
  → Employee career growth clusters  

- retention_opportunity_employees.csv  
  → Employees needing retention focus
